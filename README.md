# Pseudo Bot

This repository hosts the auto-update manifest and signed installer binaries for the Pseudo Bot desktop application.

Source code is private.

## Files

- [`update.json`](update.json) — current release manifest (version, signature, download URL)
- [Releases](../../releases) — signed installer binaries

## For users

You don't need to download anything from here directly. The application checks this repository for updates automatically on boot and installs them with one click.
